Legacy variable remap (`app/globals.css:36-41`) — all older font tokens now resolve to the current system, so any component still referencing old names renders correctly:
```
--font-inter-tight: var(--font-montserrat);
--font-playfair:    var(--font-inter-tight);   → Montserrat
--font-dm-sans:      var(--font-inter-tight);   → Montserrat
--font-dm-mono:      var(--font-geist-mono);
--font-bebas:        var(--font-inter-tight);   → Montserrat
```
So in practice there are only **3 real font families** in use (Montserrat, Fraunces, Geist Mono) despite ~6 variable names appearing in the CSS (`--font-playfair`, `--font-dm-sans`, `--font-dm-mono`, `--font-bebas` are all aliases).

## Component Conventions

**Buttons** — two systems coexist:
- Global utility classes `.btn-coral` / `.btn-ghost` (`globals.css:255-292`): height `var(--btn-height)` (52px), radius `var(--btn-radius)` (8px), font weight 800, size 16px.
  - `.btn-coral`: solid `var(--coral)` bg → `var(--coral-d)` on hover, white text.
  - `.btn-ghost`: transparent, `1.5px solid var(--line-2)` border → ink border/text on hover.
- Homepage-local "route button" pair (`app/page.tsx:692-736`), smaller/denser variant used in the CTA ladder:
  - `.route-btn-primary`: solid `#22332C` (ink) bg, `var(--cream)` text, `10px 20px` padding, `8px` radius, `13px` / weight 600 — hovers to `#EA6A47` (coral) with arrow (`.route-btn-arrow`) translating `3px`.
  - `.route-btn-ghost`: transparent, hover border/bg tint using ink at low opacity.

**CTA "ladder" pattern** (homepage, `app/page.tsx` ~2231–2394): each service/route card pairs a primary action with a secondary/ghost action side-by-side — e.g. `See Soch ↗` (`.route-btn-primary`) + `Details` (`.route-btn-ghost`), or `Details →` alone, or `Start reading →`. The "merged ladder" (`.merged-ladder-ai`) additionally nests a dropdown/popover door-button (`.merged-door-btn`, styled as `.route-btn-ghost`) beside the primary link — a compact multi-action row rather than stacked full-width buttons.

**Cards**:
- Standard content card radius: `18px` (`--radius-card`, `.gd-card`, `.wf-card`).
- Smaller cards (testimonials, social ticker): `16px`.
- Circular avatars/icons: `50%`.
- Border: `1px solid var(--line)` at rest, `var(--line-2)` or coral-tinted on hover.
- Elevation: `var(--shadow)` resting → `var(--shadow-lg)` + `translateY(-4px to -5px)` on hover (consistent hover-lift convention across `.gd-card`, `.social-ticker-card`, `.pc-video-wrap`, `.testimonials-card`).

**Pills/Chips/Badges**: radius `999px` (`--radius-chip`) throughout — `.tag-pill`, `.guide-badge`, `.gd-pill`, `.writing-row-chip`, `.testimonials-card-badge`. Typically Geist Mono, uppercase, letter-spacing `0.06–0.08em`, small size (10–13px).

**Motion**: all reveal/hover transitions key off `var(--ease)` (`cubic-bezier(.2,.7,.2,1)`) and are globally killed under `prefers-reduced-motion: reduce` (`globals.css:217-237`).
